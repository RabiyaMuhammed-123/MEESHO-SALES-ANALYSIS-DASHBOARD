Meesho Sales Analysis Dashboard | Power BI

📌 Project Overview

This project focuses on analyzing Meesho e-commerce data using Microsoft Power BI to explore product categories, pricing, discounts, ratings, seller counts, product availability, and delivery time.

The dashboard presents product-related insights through data analysis and interactive visualizations to support a better understanding of e-commerce product performance.

🎯 Objectives

- Analyze product categories and availability.
- Explore product ratings and reviews.
- Compare original prices and discounted prices.
- Analyze seller distribution across categories.
- Examine delivery time patterns.
- Present key product metrics through an interactive dashboard.

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- Data Cleaning and Transformation
- Data Analysis
- Data Visualization

📊 Dashboard Features

- Product category and availability analysis
- Ratings and review analysis
- Seller distribution by category
- Price range comparison
- Original price and discounted price analysis
- Delivery time analysis
- Interactive category filters

🔍 Key Insights

- The dashboard covers 8 product categories and 30 products.
- The overall rating displayed is 4.60.
- Clothing has the highest rating total among the categories shown.
- Home and Clothing show relatively high product availability.
- Product prices and discounts vary across categories.
- Most displayed delivery ranges fall between 4 and 9 days.
